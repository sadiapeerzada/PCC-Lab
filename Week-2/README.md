# C & OpenMP Lab Programs

This folder contains the 8 requested C programs.

## OpenMP Programs
Programs 3, 4, 6, and 8 require OpenMP.

Compile them with:

```bash
gcc filename.c -fopenmp -o filename
./filename
```

## Programs
1. Decimal to Binary, Octal and Hexadecimal
2. Merge Two Arrays
3. OpenMP Hello World
4. OpenMP Multiple Threads
5. Even or Odd — 20 Integers
6. OpenMP Even or Odd — 20 Integers
7. Armstrong Numbers — 20 Integers
8. OpenMP Armstrong Numbers — 20 Integers
